个人信息

买家主界面

  • 商品搜索框：关键词/分类/价格区间
  • 已同步卖家列表：展示卖家名、区域、上次更新时间
  • 点卖家后直接显示该卖家商品列表
  • 商品详情可下单：锁定 商品价 + 20% 确认金

买家订单与沟通

  • 订单列表：按状态筛选（待发货/已发货/退货中/已完成/争议）
  • 订单操作：确认收货、申请退货、发货前取消
  • 聊天A：用户会话聊天（类似微信，一人一会话）
  • 聊天B：订单聊天（按订单ID进入，边看订单边沟通）

卖家主界面

  • 分类管理 + 商品列表（按分类展示）
  • 商品编辑：修改标题、描述、价格、库存、图片
  • 修改后写入新版本（version递增），以最新版本为准
  • 支持商品上架/下架与历史版本追溯

卖家订单管理

  • 订单列表展示全部订单
  • 按状态过滤：待处理/待发货/已发货/退货中/争议/已完成
  • 发货动作：锁定 10% 退货保证金
  • 退货确认：确认后执行退款路径

商品多次修改与下单一致性规则（关键）

1. 商品版本化每次修改产生新 `product_version`
2. 下单快照订单写入 `product_id + product_version + price_snapshot`
3. 卖家确认卖家接单时校验版本，版本不一致可拒单并返回最新报价
4. 资金保护版本冲突时只允许取消/重下单，不允许按旧价强行结算
处理结论：即使最新商品广播未全网到达，也不会造成错误成交价。
  • 买家下单永远绑定当时看到的版本快照。
  • 卖家只能在“版本一致”时进入发货流程。
  • 版本不一致自动进入“待重报价/待买家确认”状态。
